# Симулятор муравья

Небольшое WPF-приложение с симуляцией муравья Лэнгтона. Муравей движется по полю 45 × 45 клеток и меняет их цвет.

## Запуск

Нужны Windows и .NET 8 SDK или новее. В папке проекта выполните:

```powershell
dotnet run
```

Также можно открыть `AntSimulator.csproj` в Visual Studio с поддержкой разработки классических приложений .NET.

## Правила

- На белой клетке муравей поворачивает направо, на чёрной — налево.
- Затем он перекрашивает клетку в противоположный цвет и делает шаг вперёд.
- При выходе за край поля муравей появляется с противоположной стороны.
- Оранжевый треугольник показывает положение муравья и направление движения.

Кнопка «Сгенерировать» очищает поле и возвращает муравья в центр, «Запустить» запускает или продолжает движение, «Пауза» останавливает его. Количество шагов отображается справа.
