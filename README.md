# Симулятор муравья

Простая программа на WPF. Муравей ходит по клеточному полю и меняет цвет клеток.

## Запуск

Для запуска нужен .NET 7. В папке проекта выполнить:

```powershell
dotnet run
```

## Как работает

- На белой и чёрной клетке муравей выполняет настроенное действие.
- После этого клетка меняет цвет, и муравей идёт дальше.
- Если муравей выходит за край, он появляется с другой стороны.
- Кнопка «Сгенерировать» создаёт новое поле со случайными белыми и чёрными клетками.
- Размер поля и действия муравья можно изменить в настройках.
- Кнопки «Запустить» и «Пауза» управляют симуляцией.
